# Blok M Invitation 💌

A small, playful single-page invitation website built with plain HTML, CSS, and JavaScript.

## Features
- Interactive envelope opening
- Playful invitation flow and small surprises
- Activity choices for a Blok M outing
- WhatsApp button with a pre-filled message
- Responsive layout for mobile and desktop

## Run locally
Open `index.html` in a modern browser. No build step or dependencies required.

## Deploy with GitHub Pages
1. Create a new GitHub repository (for example, `blok-m-invitation`).
2. Upload `index.html` and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then save.
6. Wait for the Pages URL to appear in the same section.

## Deploy with Vercel
Import the GitHub repository into Vercel. As this is a static HTML project, no build command is required; use the repository root as the project directory.

## Notes
- The WhatsApp action opens a chat with a pre-filled message; the visitor still needs to press Send.
- Google Fonts are loaded externally. If unavailable, the page falls back to system fonts.
